# ADR-0041 — Clean public portfolio reconstruction

- **Status:** candidate; owner GO and A/A preparation choices received 2026-09-11.
  Adoption requires the owner's I-17 signature by merge after immutable role-separated review.
- **Date:** 2026-09-11
- **Arbitrage:** public-portfolio design approved by the owner; local preparation is authorized,
  not owner signature, public exposure, or destructive execution.
- **Invariant:** I-32.
- **Decision:** D46.
- **Scope:** the observed public portfolio only, reconstructed from frozen source commits.

## Decision and acceptance boundary

The master promise is **AI work you can verify.** Missions is the sole primary
launch journey. Evidence Signal (black, white and green, high contrast, restrained
motion, proof markers, color never conveying state alone) replaces the prior visual
direction. The existing pixel bird is the shared candidate mark; it remains unpublished
until the exact asset licence and dated visual-similarity review are owner-accepted.
English is canonical; every public README has a complete governed French mirror.

A repository survives through multiple independent consumers, an independently usable
public capability, or a proved autonomous security/authority boundary. Tests are not
consumers. Single-consumer code joins its consumer; unconsumed code is deleted.
A security boundary requires a consumable artifact, autonomous contract, threat model,
and critical failure-path proof. A name alone never qualifies it.

The target has 14 certain repositories and at most six conditional repositories.
LEXICON §14 owns the exact names. Conditional names are provisional until executable
admission; failure follows the design's integration/deletion disposition. Signalement
is outside both the source inventory and target contract. `product-research` is a
private administrative repository outside this transaction and is never a third authority.

## Owner gates and recovery

The migration GO permits reversible local preparation and qualified private staging only.
I-17 adoption requires a green immutable candidate, independent architecture/security/
quality/completeness reviews, and owner signature by merge. This candidate is not that signature.
Before destructive or public mutation a second explicit owner confirmation binds the exact
transaction digest and complete deletion list. Stale source commits, concurrency, missing
rights, administrative permission, registry artifacts, admission, checks or manifest proof
block execution; no launcher success counts as completion.

Before public mutation, abandon staging to recover. Once source deletion begins, recovery
completes or retries publication from the same immutable staged targets and transaction;
obsolete public histories are not restored. Operations stop on the first failed assertion
and reconcile any interrupted external effect before retry. Full private source clones
remain inaccessible to public consumers until source-to-target coverage and post-cutover
smoke checks pass; their deletion then requires the verified cleanup step. Minimal protected
legal evidence follows independent justified retention, is unavailable to routine automation,
and is never published as Git history or ordinary logs.
