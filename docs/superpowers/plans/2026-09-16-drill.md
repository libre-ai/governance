# Drill Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create `libre-ai/drill`, the transverse tool that turns the probing of one external repository into mechanism-level decisions proven by contract, and project those decisions into the target repository.

**Architecture:** `contracts` owns `probe-brief.v1`, `probe-report.v1` and the WIT `drill-core-v1`; the pure Rust crate `libre-ai-drill` seals reports, enforces sentinel gates, aggregates verdicts into `evidence-report.v1`, draws the deterministic verification sample and checks decision coherence; the Bun package `@libre-ai/drill` provides `pin | dig | prove | decide`, reads git and writes files. Drill keeps no probing result: decisions are projected into the target repository, and only Drill's own error vectors and reliability counters persist.

**Tech Stack:** Rust stable pinned by the fleet toolchain (clippy zero warning, no `unwrap`/`panic` outside tests), `cargo component` for the WIT component, Bun pinned by `check:bun:runtime`, TypeScript strict, Ajv 8 (2020-12, strict), Biome, Playwright not required, GitHub Actions pinned by SHA, REUSE, DCO.

**Spec:** `docs/superpowers/specs/2026-09-16-drill-design.md` · **ADR:** `docs/adr/0043-drill-verified-repository-probing.md`

## Global Constraints

- Security precedes quality, performance and completeness. The core performs no I/O; time, bytes, nonce and `git apply --check` results are inputs.
- Probed repositories are data (ADR-0032 D1). Drill never executes source code; runners execute under attestation.
- No `executed` claim without an attestation; a caller-declared attestation caps the verdict (`attestation.signed = indeterminate`).
- Every expected sentinel absent from a report is a `fail`; `sentinel.positive-control` is mandatory in every brief.
- No personal data in any brief, report, evidence-report or fixture: forge snapshots are counters and titles; artifacts are referenced by URN and digest.
- `contracts` remains the only schema authority; Rust types are a disposable projection (ADR-0037 D1). Generated TypeScript types come from the schemas, never hand-written.
- Repository birth follows ADR-0038/I-30: private empty remote, merged attestation, then public exposure. No public repository before the attestation is merged.
- Licences: Apache-2.0 for crate, package, schemas, scripts and fixtures; CC-BY-4.0 for documentation; REUSE and DCO mandatory; no `Co-Authored-By` trailer.
- No machine-local path in tracked files; no force push; squash merges with DCO sign-off.
- Execute from a dedicated worktree based on `origin/main` of each repository touched; the portfolio big-bang branches (ADR-0041 candidate) remain untouched.

### Task 4: Implement the pure core `libre-ai-drill`

**Files:**

- Create: `crates/libre-ai-drill/src/{lib.rs, seal.rs, sentinel.rs, verdict.rs, sample.rs, decision.rs, error.rs}`
- Create: `crates/libre-ai-drill/tests/{rules.rs, vectors.rs}`
- Create: `fixtures/rules/*.json` (one vector per rule: dangling id, foreign sourceId, missing sentinel, digest mismatch, declared attestation cap, patch not applying) and the campaign vectors (inert gate, fabricated stub, propagated invalidation)
- Create: `crates/libre-ai-drill/Cargo.toml` (`serde`, `serde_json`, `sha2`; no async, no I/O crate)

**Steps (TDD, one rule at a time):**

- [ ] Red: a test loading `fixtures/rules/missing-sentinel.json` expects `evidence-report.status == fail` with `reasonCode sentinel.missing`. Green: implement `sentinel.rs`. Repeat for the six rules.
- [ ] Sealing: canonical bytes (RFC 8785 order), SHA-256; test that key reordering does not change the digest and any byte change does.
- [ ] Verdict aggregation by domination: any `fail` ⇒ `fail`; else any `indeterminate` ⇒ `indeterminate`; else `pass`. Test the three cases and the declared-attestation cap.
- [ ] Sampling: seed = `sha256(sealedDigest || nonce)`; size `max(10, ceil(0.25 * claims))` plus all executed claims cited by `copy`/`adapt` decisions; test determinism and distinctness across nonces.
- [ ] Decision coherence: every `claimRefs` exists; `copy`/`adapt` cite at least one `executed` claim with `pass` on `target.gates`; `reject-by-measure` cites at least one `measure` claim.
- [ ] Types are derived from the schemas (embedded schema registry validates inputs strictly before deserialisation); no domain type is persisted.
- [ ] `cargo clippy -- -D warnings`, `cargo test`, `cargo component build` for `drill-core-v1`.

**Tests:** unit + vector suites; property test that no input panics (fuzz on the JSON surface). **Acceptance:** six rules green, campaign vectors green, zero `unwrap` outside tests, component builds.

### Task 5: Implement the Bun package `@libre-ai/drill`

**Files:**

- Create: `packages/drill/src/{cli.ts, pin.ts, dig.ts, prove.ts, decide.ts, git.ts, digest.ts, core.ts}` (`core.ts` loads the WIT component)
- Create: `packages/drill/src/generated/` (types generated from the contracts schemas by the contracts toolchain, never edited)
- Create: `packages/drill/templates/brief/*.md` (one brief template per mechanism family: lint rule, hook, skill, benchmark, e2e observer)
- Create: `packages/drill/test/{pin.test.ts, dig.test.ts, prove.test.ts, decide.test.ts}`

**Steps:**

- [ ] `pin`: clone into a caller-provided directory at an exact SHA, compute per-element licences from `LICENSE*`, `package.json`, `Cargo.toml`, SPDX headers and REUSE, write `source.json`; forge snapshot limited to counters and titles via `gh` when available, otherwise `forge: null`.
- [ ] `dig`: render a `probe-brief.v1` from a template plus the pinned source; refuse a brief without `sentinel.positive-control` or with empty criteria; write the brief digest.
- [ ] `prove`: read a report, validate it against `probe-report.v1` before any other read, hash every artifact, run `git apply --check` for each patch on its base in a scratch worktree, draw the nonce, call the core, write the sealed report and the `evidence-report.v1`.
- [ ] `decide`: call the core coherence check, then write the projection files (`patch`: `git format-patch` ready; `spec`: Markdown under `docs/superpowers/specs/` of the target copy; `adr`: stub in governance format; `skill-admission`: ADR-0025 dossier stub; `drill-vector`: fixture under `fixtures/`).
- [ ] Every command prints a `{ data, meta }` JSON envelope on `--json`; exit codes: 0 pass, 1 fail, 2 indeterminate, 64 usage.
- [ ] `bun run typecheck`, `bun run lint` (`biome ci`), `bun test`.

**Tests:** focused tests on a local fixture repository at a known SHA; the four refusals of the spec §8.2. **Acceptance:** all commands green on the fixture repository; refusals observed with the documented exit codes.
